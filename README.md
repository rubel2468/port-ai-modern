# হোটেল বুকিং ওয়েবসাইট (Hotel Booking Website)

এটি একটি আধুনিক এবং পূর্ণাঙ্গ হোটেল বুকিং ওয়েব অ্যাপ্লিকেশন, যা ব্যবহারকারীদের হোটেল খোঁজা, রুম বুকিং করা এবং অনলাইনে পেমেন্ট করার সুবিধা প্রদান করে।

## টেকনোলজি স্ট্যাক (Technology Stack)

ওয়েবসাইটটি তৈরি করতে নিম্নলিখিত আধুনিক প্রযুক্তিগুলো ব্যবহার করা হয়েছে:
- **ফ্রন্টএন্ড ও ব্যাকএন্ড:** [Next.js](https://nextjs.org/) (Version 15) - শক্তিশালী React ফ্রেমওয়ার্ক।
- **ডেটাবেস:** [MongoDB](https://www.mongodb.com/) (Mongoose ORM ব্যবহার করে) - ডেটা সংরক্ষণের জন্য।
- **অথেনটিকেশন (Authentication):** [NextAuth.js](https://next-auth.js.org/) - নিরাপদ ইউজার লগইন এবং রেজিস্ট্রেশনের জন্য।
- **স্টাইলিং (Styling):** [Tailwind CSS](https://tailwindcss.com/) - রেস্পন্সিভ ও মডার্ন ইউজার ইন্টারফেস ডিজাইনের জন্য।
- **পেমেন্ট গেটওয়ে (Payment Gateway):** [SSLCommerz](https://sslcommerz.com/) - নিরাপদ অনলাইন লেনদেন বা পেমেন্ট সম্পন্ন করার জন্য।
- **আইকন (Icons):** [Lucide React](https://lucide.dev/) - আধুনিক আইকন ব্যবহারের জন্য।
- **ইমেইল সার্ভিস:** [Nodemailer](https://nodemailer.com/) - ইউজারদের ইমেইল নোটিফিকেশন পাঠানোর জন্য।

## ওয়েবসাইটটি কীভাবে কাজ করবে? (How the Website Works?)

এই ওয়েবসাইটটি মূলত কয়েকটি প্রধান ফিচারের ওপর ভিত্তি করে কাজ করে। এর কার্যপ্রণালী নিচে বিস্তারিতভাবে আলোচনা করা হলো:

### ১. ইউজার রেজিস্ট্রেশন ও লগইন (User Authentication)
- নতুন ব্যবহারকারীরা তাদের ইমেইল ও পাসওয়ার্ড বা অন্যান্য মাধ্যমে অ্যাকাউন্ট তৈরি করতে পারবেন।
- NextAuth এর মাধ্যমে অত্যন্ত সুরক্ষিত লগইন সিস্টেম তৈরি করা হয়েছে।
- লগইন করার পর ইউজাররা তাদের নিজস্ব ড্যাশবোর্ডে যেতে পারবেন, যেখানে তারা তাদের পূর্বের বুকিং হিস্ট্রি এবং প্রোফাইলের তথ্য দেখতে ও এডিট করতে পারবেন।

### ২. হোটেল এবং রুম খোঁজা (Search Hotels & Rooms)
- ওয়েবসাইটের হোমপেজে বিভিন্ন জনপ্রিয় হোটেল এবং তাদের বিস্তারিত তথ্য (যেমন: হোটেলের ছবি, লোকেশন, সুযোগ-সুবিধা ইত্যাদি) প্রদর্শন করা হবে।
- ইউজাররা তাদের পছন্দমতো হোটেল নির্বাচন করে সেখানে কোন ধরনের রুম বর্তমানে খালি আছে তা দেখতে পারবেন।
- এখানে ফিল্টারিং সিস্টেম থাকবে, যার মাধ্যমে ইউজাররা রুমের ধরন, মূল্য এবং অন্যান্য সুবিধার ওপর ভিত্তি করে সহজে নিজেদের পছন্দের রুম খুঁজে নিতে পারবেন।

### ৩. রুম বুকিং প্রক্রিয়া (Booking Process)
- পছন্দসই রুম নির্বাচন করার পর ইউজাররা সেটি বুক করার জন্য আবেদন করতে পারবেন।
- বুকিংয়ের সময় ইউজারকে চেক-ইন (Check-in) এবং চেক-আউট (Check-out) এর সঠিক তারিখ নির্ধারণ করতে হবে।
- বুকিং সম্পন্ন হলে এর সমস্ত ডেটা ডেটাবেসে (MongoDB-তে) সংরক্ষিত থাকবে এবং অ্যাডমিন তা দেখতে পারবেন।

### ৪. পেমেন্ট সিস্টেম (Payment System)
- বাংলাদেশের অন্যতম জনপ্রিয় পেমেন্ট গেটওয়ে **SSLCommerz** এর মাধ্যমে ইউজাররা নিরাপদে অনলাইনে পেমেন্ট করতে পারবেন (বিকাশ, রকেট, নগদ, ডেবিট/ক্রেডিট কার্ড ইত্যাদি দিয়ে)।
- পেমেন্ট সফলভাবে সম্পন্ন হলে একটি বুকিং কনফার্মেশন মেসেজ বা ইমেইল সরাসরি ইউজারের কাছে পাঠানো হবে (Nodemailer ব্যবহার করে)।
- প্রতিটি পেমেন্টের হিস্ট্রি ডেটাবেসে পেমেন্ট মডেলে সংরক্ষিত থাকবে, যা ইউজার এবং অ্যাডমিন উভয়েই দেখতে পারবেন।

### ৫. অফার এবং প্রমোশন (Offers & Promotions)
- অ্যাডমিন প্যানেল থেকে বিভিন্ন সময় ছাড়, ডিসকাউন্ট, প্রোমোকোড বা স্পেশাল অফার দেওয়া যাবে।
- ইউজাররা বুকিং এর সময় সেই প্রোমোকোড ব্যবহার করে নির্ধারিত ছাড় উপভোগ করতে পারবেন।

### ৬. রিভিউ এবং রেটিং (Reviews & Ratings)
- কোনো হোটেলে থাকার পর বা সার্ভিস নেওয়ার পর ইউজাররা তাদের অভিজ্ঞতা জানিয়ে ওয়েবসাইটে রিভিউ ও রেটিং দিতে পারবেন। এটি অন্যান্য নতুন ইউজারদের সিদ্ধান্ত নিতে সাহায্য করবে।

### ৭. নিউজলেটার এবং সাবস্ক্রিপশন (Newsletter & Subscription)
- নতুন অফার, ডিসকাউন্ট বা আপডেট পেতে ইউজাররা তাদের ইমেইল দিয়ে নিউজলেটারে সাবস্ক্রাইব করে রাখতে পারবেন।

## প্রজেক্টটি লোকাল কম্পিউটারে রান করার নিয়ম (How to run locally)

ডেভেলপমেন্ট বা টেস্ট করার জন্য আপনার কম্পিউটারে প্রজেক্টটি চালু করতে নিচের ধাপগুলো অনুসরণ করুন:

১. আপনার টার্মিনাল বা কমান্ড প্রম্পট ওপেন করে প্রজেক্ট ফোল্ডারে যান:
   ```bash
   cd e:\Project\Hotel-booking
   ```

২. প্রজেক্টের প্রয়োজনীয় সকল প্যাকেজ বা ডিপেন্ডেন্সি ইন্সটল করার জন্য নিচের কমান্ডটি রান করুন:
   ```bash
   npm install
   ```

৩. প্রজেক্টের রুট ডিরেক্টরিতে `.env.local` নামে একটি ফাইল তৈরি করুন এবং সেখানে আপনার প্রোজেক্টের সিক্রেট ভেরিয়েবলগুলো (যেমন: MongoDB URI, NextAuth Secret, SSLCommerz Store ID & Password ইত্যাদি) সেট করুন।

৪. এবার প্রজেক্টটি লোকাল সার্ভারে রান করার জন্য নিচের কমান্ডটি দিন:
   ```bash
   npm run dev
   ```

৫. প্রজেক্ট রান হওয়ার পর আপনার ওয়েব ব্রাউজারে গিয়ে `http://localhost:3000` ঠিকানায় ভিজিট করুন। আপনি ওয়েবসাইটটি দেখতে পাবেন।
